# 🌾 Productos Naturales de la Tierra

## 📌 Descripción del proyecto
Este es un proyecto web de un emprendimiento dedicado a la distribución de sacos de quinua y trigo en la ciudad de La Paz, Bolivia.

## 🎯 Objetivo
Crear una página web promocional utilizando HTML5 y CSS3 con estructura semántica.

## 🏢 Emprendimiento
Distribución de productos naturales (quinua y trigo) al por mayor y menor.

## 💻 Tecnologías usadas
- HTML5
- CSS3

## 📍 Ubicación
La Paz - Bolivia

## 👨‍💻 Autor
Proyecto estudiantil de Emprendimiento Digital
